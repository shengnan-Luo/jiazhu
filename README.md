# 夹注：英文网页生词释义

在英文网页里，把你可能不认识的单词挑出来，**直接在单词后面显示中文**。英文句子保持原样，读到生词时扫一眼后面的中文就能继续读下去，不用整段对照，也不用另外查词。

```
The results corroborate证实 our hypothesis假设 that the anomalous异常的 signal ...
```

支持 Chrome 和 Edge。

## 安装

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 打开右上角（Edge 在左下角）的 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本项目里的 `extension` 文件夹
4. 安装后会自动打开设置页。已经打开的网页需要刷新一次才会生效

## 怎么用

| 操作 | 效果 |
|---|---|
| 正常阅读 | 生词后面自动显示中文。同一段里重复出现的词只在第一次显示，之后画虚线，鼠标放上去显示 |
| 点击标注过的词 | 弹出卡片：音标、完整释义、所属词表。可以 **认识了，不再标注**、**加入生词本**、**AI 讲解**、**翻译整句** |
| 链接里的词 | 普通点击照常打开链接，**Alt+点击** 才弹出卡片 |
| 选中任意单词、短语或段落 | 选区右上角出现一个小圆点，点击后在右侧弹出释义：单词显示词典释义（词典里没有就用 DeepLX/AI 翻译），短语和段落显示翻译。单词和短语都能 **加入生词本**、**AI 讲解** |
| **Alt+W** | 显示/隐藏本页所有释义（想直接读英文时用）。可在 `chrome://extensions/shortcuts` 修改 |
| 工具栏图标 | 本站开关、全局开关、调整标注范围、开关 AI |

释义颜色：**青色** 是词典释义，**紫色** 是 AI 按上下文改过的释义和 AI 找出的短语，**橙色** 是生词本里的词。

复制英文、按 Ctrl+F 搜索时都不会带上中文释义。

### 标注哪些词

每个词按它出现的**最低一级**考试词表分档：

| 档 | 内容 |
|---|---|
| 基础 | 中考、高考词，以及最常用的约 3000 词 |
| 四级 | 大学英语四级词汇 |
| 六级 | 大学英语六级词汇 |
| 考研/雅思/托福 | 这三类考试的词汇 |
| GRE/低频 | GRE 词，以及不在任何词表中、按词频排在 2 万名以后的词 |
| 专业/罕见 | 词典收录但不常用的词，多是专业术语，如 perovskite → 钙钛矿 |

默认标注 **六级及以上** 和专业词。标多了就在弹窗里调到“考研/雅思/托福及以上”，标少了就调到“四级及以上”。个别词在网页上点一下就能改：

- 认识的词：点 **认识了**，以后不再标注（可在设置页撤销）
- 不认识但没被标出的词：选中后点小圆点，**加入生词本**

用一两周之后，标注会越来越贴合你自己的词汇量。

## AI 语境释义（建议开启）

离线词典只能给出每个词的**第一个义项**，而这个义项经常不是论文里的意思（比如 hybrid 显示“混血儿”、yield 显示“生产量”）。开启 AI 后，你正在看的段落会发给大模型，它会：

- 按上下文改写每个生词的释义（yield → 产率）
- 补上词典里没有的新术语
- 找出段落里的短语和固定搭配（每段最多 5 个），释义用〔〕放在短语末尾，如 give rise to〔导致〕。短语只能靠 AI 识别，不开 AI 就没有
- 指出常见词的少见用法，如 novel → 新颖的

怎么看出 AI 在工作：段落滚动到屏幕上一两秒后，青色释义变成紫色，并出现〔〕短语释义；点开单词卡片会多一行紫底的“语境：…”。工具栏弹窗里会显示“本页 AI 已处理 N 段”；如果 Key 填错或余额不足，网页右下角会弹出一次错误提示。

设置方法（以 DeepSeek 为例）：

1. 在 DeepSeek 开放平台注册并创建 API Key
2. 打开插件设置页的 **AI 语境释义**：接口地址填 `https://api.deepseek.com/v1`，填入 Key，模型名填 `deepseek-chat`（以官方文档为准）
3. 点 **测试连接**，成功后勾选 **开启 AI 语境释义**

任何兼容 OpenAI 接口的服务都能用（硅基流动、阿里云百炼、Moonshot 等），填对应的地址和模型名即可。

说明：

- 只处理滚动到的段落；参考文献列表不发送。同一段落的结果在浏览器关闭前会缓存，不会重复计费
- 一篇论文大约消耗几万 token，用 DeepSeek 这类模型费用很低
- 段落原文会发送到你填写的 AI 服务。阅读不公开的内容时，可以在弹窗里关掉本站或关掉 AI
- API Key 只保存在本机浏览器中

## DeepLX 翻译

用于 **翻译整句**、选中文字后的翻译，以及查词典里没有的词。没有配置或调用失败时，会自动改用 AI 翻译。

- 公共服务 `api.deeplx.org`：直接调用 `https://api.deeplx.org/translate` 只会返回一个说明链接（[linux.do/t/topic/111737](https://linux.do/t/topic/111737)），需要用 linux.do 账号获取个人 key，并把 key 放进地址里。常见写法是 `https://api.deeplx.org/<你的key>/translate`，具体以说明帖为准（此格式未经验证）
- 自己部署的 DeepLX：填 `http://localhost:1188/translate` 之类的地址；如果启动时设置了 `-token`，就把它填到 Token 一栏

填好后点 **测试翻译**。

## 生词本

- 生词本记录单词、释义、**你遇到它的原句**和来源网页
- 设置页可以搜索、移出，以及 **导出 CSV**，导入 Anki 后正面放单词、背面放释义和原句
- **导出备份/导入备份** 用来换电脑或重装插件，备份里不含 API Key

## 已知局限

- 离线释义只取词典的第一个义项，经常不贴合语境。开启 AI 后会被替换
- 不支持 PDF：浏览器自带的 PDF 阅读器不允许插件修改。读 PDF 时可以改看出版社的 HTML 全文页
- 少数用 React 等框架频繁重绘的网页，可能偶尔显示异常。遇到时在弹窗里关掉本站
- 更新或重新加载插件后，已经打开的网页要刷新

## 文件结构

```
extension/              插件本体（加载这个文件夹）
  manifest.json
  common.js             默认设置、存取函数
  background.js         词典查询、DeepLX、AI 调用
  content/              注入网页：标注、卡片、划选翻译
  popup/                工具栏弹窗
  options/              设置页、生词本
  dict/                 预处理好的词典（由 tools/build_dict.py 生成）
tools/build_dict.py     从 ECDICT 生成 dict/ 下的词典文件
```

### 重新生成词典

词典数据来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可，许可文本见 [extension/dict/LICENSE-ECDICT](extension/dict/LICENSE-ECDICT)）。想调整分档规则或释义的提取方式时，下载 `ecdict.csv` 后运行：

```bash
python tools/build_dict.py path/to/ecdict.csv extension/dict
```

然后在扩展管理页点插件的 **重新加载**。
